About Our Project

This project demonstrates automated cloud infrastructure provisioning and web application deployment using Terraform and AWS EC2. Apache is used to host the website.

Technologies We Use

Tools and technologies used in our deployment process.

☁️

AWS

Cloud platform used to provide computing infrastructure.

⚙️

Terraform

Infrastructure as Code tool used to create AWS resources.

🖥️

EC2

Virtual server used to run and host our website.

🌐

Apache

Web server used to serve our HTML website to visitors.

🔄

GitHub Actions

CI/CD tool used to automate website deployment whenever code changes are pushed to GitHub.

🔐

AWS IAM & OIDC

Provides secure authentication and access management between GitHub Actions and AWS.

🚀

AWS Systems Manager

Used to remotely execute deployment commands on the EC2 instance.
